Cybersecurity Evaluation Logic:

🔥 Windows Firewall: If any Windows Firewall profile (Domain, Private, Public) is disabled (OFF) or deviates from baseline, it immediately triggers a HIGH RISK alert.

📁 Multi-Folder & Subfolder Scope: Files across all configured monitored directories are discovered and hashed recursively using SHA-256.

⚡ File Risk Rules: Executable scripts (.bat, .ps1, .exe, etc.) and security/firewall configurations (config, firewall, .conf) added or altered are classified as HIGH risk. Standard documents added or modified are MEDIUM risk. Baseline-identical files are LOW risk.
